# Semakan versi 26 September 2026

## Lulus

- JavaScript lulus semakan sintaks.
- Aliran pelayar: nama → sambutan → 4 tamadun → 6 sungai → 4 objek arkib → simulasi → hujan → laporan akhir.
- Markah maksimum 100 dan kemajuan 100% diuji melalui ujian logik.
- Laluan pembetulan dalam pelayar menghasilkan 92/100 seperti dijangka: satu label salah (−1), satu arkib salah (−2), sampah pernah diabaikan (−2), saliran dicuba sebelum pelawat selamat (−3).
- Sampah bertukar kepada kawasan bersih; tembok ditanda untuk rawatan; kanopi muncul; penghadang dipasang; air surut selepas saliran dibuka.
- Alat tidak boleh digunakan sebelum ejen dekat. Tugasan yang sudah selesai tidak menggandakan markah.
- Rekod laporan membezakan keutamaan keselamatan daripada kesilapan alat lain.
- Susunan label dan arkib berubah antara sesi; urutan rawak turut diuji secara programatik.
- Nama dipaparkan sebagai teks terlepas, bukan kod HTML.
- Alternatif papan kekunci berfungsi sepanjang permainan. Klik koordinat sebenar pada borang mula juga disahkan.
- Paparan responsif 390 × 844: tiada limpahan mendatar keseluruhan halaman. Peta sendiri boleh dileret secara mendatar.
- Pengendali pointer untuk seret, bergerak dan lepaskan pada pin lulus ujian logik.
- Tiada ralat JavaScript direkodkan dalam pelayar semasa aliran lengkap.
- Aset dan laluan fail tempatan disemak; ZIP mengandungi index.html pada aras utama.

## Batas semakan

Ujian dilakukan dalam pelayar desktop dan emulasi saiz telefon, bukan pada perkakasan iPhone/Android sebenar. Seretan fizikal penuh belum disahkan kerana pemetaan koordinat pelayar ujian berbeza daripada paparan; alternatif pilih label kemudian pin disahkan.

Butang laporan menjana fail teks menggunakan Blob. Isyarat muat turun pelayar ujian tidak diterima, jadi simpanan fail melalui pelayar tersebut belum disahkan. Rekod yang sama boleh dibaca pada skrin laporan akhir. Uji muat turun dalam Chrome/Edge/Safari sasaran selepas penerbitan.

Penerbitan sebenar ke GitHub Pages belum dilakukan; pakej disediakan untuk muat naik ke repositori baharu.

Pembukaan CODE ERROR: paparan amaran dan peralihan automatik selepas kira detik disahkan dalam pelayar; tiada ralat JavaScript. Ujian logik misi sedia ada masih lulus.
